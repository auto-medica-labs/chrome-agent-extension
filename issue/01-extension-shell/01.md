# What to build
A Chrome extension manifest and Vite build pipeline that opens a React-based side panel. This slice delivers the minimal end-to-end shell: the extension installs, the side panel opens persistently, and a first-run empty state prompts the user to configure settings. See PRD sections "Settings & Configuration — FR-12", "UI & Interaction — FR-10", and "Non-functional requirements — Platform / Extensibility".

# Acceptance criteria

- A `manifest.json` (v3) declares the `sidePanel` permission and points to the built HTML entry.
- Vite bundles React + shadcn/ui into the extension output without runtime errors.
- Clicking the extension icon (or action) opens the side panel on Chrome 114+.
- The side-panel React app renders a non-chat empty state when no valid profile exists, with a clear CTA to open Settings.
- Settings panel is reachable from the side panel without a full page reload (client-side navigation or state toggle).
- `chrome.storage.local` is confirmed writable and readable from the side-panel context.
- A new developer can run `bun install && bun run build` and produce loadable extension artifacts.
