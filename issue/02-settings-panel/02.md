# What to build
A settings panel inside the side panel where users can create, save, switch, and test multiple provider/model profiles. API keys and profile data persist in `chrome.storage.local`. See PRD sections "Settings & Configuration — FR-01 through FR-04" and "Non-functional requirements — Security".

# Acceptance criteria

- Users can input and save API base URL, model name, and API key as a named profile.
- Multiple profiles can be saved; users can switch the active profile and delete existing ones.
- A "Test connection" button sends a lightweight request to the configured endpoint and surfaces clear success or failure feedback.
- Default preset profile is OpenAI (user must supply their own key).
- All profile data and keys are stored via `chrome.storage.local`; no data leaves the browser.
- Changing the active profile immediately updates the chat context to use the new endpoint/model.
- Opening settings from the chat view does not destroy or reset the current in-memory conversation.
